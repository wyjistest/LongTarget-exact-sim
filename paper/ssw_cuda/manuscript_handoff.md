# Manuscript Handoff

## Defensible result

The work established exact CUDA implementations for the modified SSW L1/L2
pre-align-selection contract and the L3 forward endpoint on broad consumed
regression corpora. Integrating those layers with selected-only CPU
reverse-start and traceback exposed a large-workload continuation contract
failure and severe negative performance at the earlier completed checkpoints.

## Required framing

Use `forward checkpoint`, `consumed regression`, `development checkpoint`, and
`negative performance evidence`. State the exact denominators: Phase 5
623 primary tasks, Phase 6 625 primary cases, and Phase 7 26 complete clean
comparisons followed by one technical correctness failure.

Do not use `safe GPU backend`, `full SSW replacement`, `all alignments exact`,
`fresh-holdout promoted`, `10x acceleration`, or `Bioinformatics-ready`.

## Publication route

The Bioinformatics Applications Note widening claim is closed. A bounded
negative-result or checkpoint methods report may be considered if the venue
accepts incomplete backend work and the failure inventory, limitations, and
all non-promotion language remain attached. A software or release paper is not
supported by this epoch.

## Handoff boundary

Future work is a new program epoch. It must localize the failed selected
attempt without using it as a hidden allowlist, change the architecture before
new execution, preregister a fresh holdout, and establish a new performance
feasibility gate. It must not rewrite the Phase 7 no-go or reuse consumed data
as promotion evidence.
